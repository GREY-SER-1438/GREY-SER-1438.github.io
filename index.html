Настройка системы контроля версий Git

Знакомство с Git, удалёнными репозиториями GitHub и публикацией статического сайта с помощью GitHub Pages.

Перейти к этапам Открыть GitHub

Цель работы

Освоить базовые команды Git и научиться публиковать готовый проект в интернете.

Git

Распределённая система контроля версий, которая позволяет сохранять историю изменений проекта и возвращаться к предыдущим версиям.

GitHub

Онлайн-сервис для хранения Git-репозиториев, совместной работы над проектами и публикации сайтов через GitHub Pages.

Порядок выполнения

Основные шаги, необходимые для настройки Git и публикации проекта.

01

Установка Git

Скачайте Git с официального сайта и выполните обычную установку. После установки проверьте, что Git доступен в терминале. 

git --version
02

Настройка пользователя

Укажите имя и электронную почту. Эти данные будут записываться в историю коммитов. 

git config --global user.name "Ваше Имя"
git config --global user.email "ваша@почта.com"
03

Создание локального репозитория

Откройте папку проекта в Visual Studio Code, запустите терминал и инициализируйте Git-репозиторий. 

git init
git add .
git commit -m "Первый коммит"
04

Создание репозитория на GitHub

Создайте новый репозиторий в своём аккаунте GitHub, после чего свяжите его с локальным проектом. 

git remote add origin https://github.com/USERNAME/REPOSITORY.git
git branch -M main
git push -u origin main
05

Публикация через GitHub Pages

В настройках репозитория откройте раздел Pages, выберите публикацию из ветки main и корневой папки проекта. После сохранения GitHub создаст публичную ссылку на сайт. 

# Пример адреса готового сайта:
https://USERNAME.github.io/REPOSITORY/
Результат работы

В ходе практической работы были изучены основные команды Git, выполнена настройка пользователя, создан локальный и удалённый репозиторий, а статический сайт опубликован с помощью GitHub Pages.
